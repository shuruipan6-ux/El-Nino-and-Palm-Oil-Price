# Data directory

Raw and processed datasets are intentionally excluded from Git. This directory documents how data will be obtained, validated, and transformed.

## Folder rules

- `raw/`: immutable downloads exactly as obtained from the source.
- `external/`: manually obtained reference tables that are not generated by this project.
- `processed/`: cleaned monthly tables created by project code.

Only `.gitkeep` placeholders are tracked. Do not commit credentials, licensed files, or large raw datasets.

## Data feasibility gate

Modeling should not begin until the following conditions are met:

1. Climate, physical supply, and price histories can be joined to a common monthly calendar.
2. The sample is long enough to contain multiple ENSO and palm-oil market regimes.
3. Publication dates or defensible lags are available for every predictor.
4. Missing months, revisions, units, and seasonal definitions are documented.
5. Redistribution rights are checked before any sample data are committed.

## Planned output table

The first processed deliverable will be a monthly point-in-time table with one row per forecast origin. It will preserve both the economic reference month and the date on which each observation became available.

Expected keys:

- `reference_month`
- `forecast_origin_date`
- `source_release_date`
- `variable_name`
- `value`
- `source_id`
- `is_revised`

The wide modeling table will only be created after this long-form audit table passes validation.
